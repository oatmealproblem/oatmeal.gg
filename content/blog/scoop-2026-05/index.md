## Paint a Galaxy

The rewrite/redesign released in March promised greater productivity from a code technical perspective, and a UI that could more easily adapt to additional features. Good news, it worked! I've been able to release many large and small features the past 2 months:

- choose placement of unique systems (by setting `initializier`s)
- set custom solar system names
- configurable snap-to-grid with various grid types (square, triangle, hex, radial)
- new drawing tools (ellipse, rectangle, line)
- export and import projects
- clone projects
- pan the map with arrows/WASD
- step-specific canvas opacity settings (so you can optionally reference your painting or uploaded image in the Tweak step)
- in-app guides for Gigastructural Engineering core
- various fixes to both the app and the mod

Paint a Galaxy is still my focus. In the coming weeks, I plan to work on:

- custom fallen empire spawn areas
- move systems with a drag & drop tool
- symmetry tools

Then I'll run another poll in Discord to help drive priorities.
